# tagi-consulting_page

TAGI Consulting 公式Webサイト（1ページ構成の静的サイト）です。
HTML5 / CSS3 / 最小限の JavaScript のみで構成し、外部フレームワークやビルド工程はありません。

## ファイル構成

```
/
├─ index.html               サイト本体（全セクション・メタ情報・構造化データ）
├─ assets/
│  ├─ css/style.css         デザイントークン（:root）とすべてのスタイル
│  ├─ js/main.js            スマホメニュー、ヘッダー、スマホ下部ボタン、アドレスコピー
│  └─ img/
│     ├─ logo.svg           ロゴ（構造化データ用）
│     ├─ favicon.svg        ファビコン
│     ├─ apple-touch-icon.png
│     └─ ogp.png            SNS共有用画像（1200×630）
├─ robots.txt / sitemap.xml
├─ tools/ogp.html           ogp.png の元データ（公開不要）
└─ design-spec.md           デザイン仕様書（公開不要）
```

## プレビュー方法

```bash
python3 -m http.server 8000
# ブラウザで http://localhost:8000/ を開く
```

`index.html` を直接ブラウザで開いても表示できます。

## 編集方法

| 変更したい内容 | 編集箇所 |
|---|---|
| 文章 | `index.html` の該当セクション（`id="issues"` `id="services"` `id="ai"` `id="strengths"` `id="process"` `id="profile"` `id="faq"` `id="contact"`） |
| 色・文字サイズ・余白 | `assets/css/style.css` 冒頭の `:root` のデザイントークン |
| FAQ | `index.html` の `<details class="c-accordion">` と、`<head>` 内の FAQPage 構造化データの両方を同じ内容に更新 |
| メールアドレス | `index.html` 内の `mailto:` リンク（2か所）、表示テキスト、構造化データの `email` |
| メールの件名・本文テンプレート | お問い合わせボタンの `mailto:` の `subject` / `body`（URLエンコードが必要） |
| ページタイトル・説明文 | `<title>`、`meta description`、`og:*` |
| SNS共有画像 | `tools/ogp.html` を編集し、1200×630 でスクリーンショットを撮って `assets/img/ogp.png` を差し替え |

ロゴはインラインSVG（`index.html` 冒頭の `<symbol id="logo-mark">`）で、ヘッダー・フッター・プロフィールで共用しています。

## 掲載ルール（編集時に必ず守ること）

- 代表者の表示名は「a.kato」のみ。本名、顔写真、個人SNS、電話番号、住所は掲載しない。
- 過去の所属会社名、顧客名、案件名、案件を推測できる内容・数値・時期、前職の成果や表彰歴は掲載しない。
- 資格は名称のみ（取得年は掲載しない）。
- 存在しない顧客・導入事例・成果数値・従業員・組織体制を書かない。
- AIエージェントの業務フロー図は「ご支援イメージ（架空の例）」として扱い、導入実績として表現しない。
- 料金は「個別見積もり」。
- 上記は本文だけでなく、メタ情報、alt属性、構造化データ、HTMLコメント、画像ファイル名にも適用する。

## 動作確認結果（2026年10月23日）

ローカルサーバー上で、ヘッドレスChrome（Puppeteer）を使って確認しました。

| 項目 | PC（1440px） | スマートフォン（390px） |
|---|---|---|
| 横スクロール（`scrollWidth` が画面幅を超えない） | なし（1440） | なし（390） |
| 画面外にはみ出す要素 | なし | なし |
| ページ内リンクのリンク切れ | なし | なし |
| JavaScriptエラー・読み込み失敗 | なし | なし |
| Webフォントの読み込み | 3書体とも読み込み済み | 同左 |
| 12px未満の文字 | なし | なし |
| グローバルナビ | クリックで該当セクションへ移動 | メニューの開閉、リンク選択後に自動で閉じる |
| FAQ（開閉） | 開閉できる | 開閉できる |
| メール送信ボタン | `mailto:` に件名・本文テンプレート付きで設定 | 同左。下部固定ボタンはファーストビュー通過後に表示 |
| h1 の数 | 1 | 1 |

このほか、以下を確認しています。

- 主要な文字色と背景色の組み合わせは、すべてコントラスト比 4.5:1 以上（WCAG 2.2 AA）。
- 構造化データ（ProfessionalService、FAQPage）は JSON として正しく読み込める。
- 重複する `id` はない。
- 公開対象の全ファイル（HTML、CSS、JS、SVG、README、画像ファイル名、PNGのメタデータ）に、本名・過去の所属や案件に関する情報・住所・電話番号が含まれていない。
